# X-Ray Mirror 性能优化补丁

`patch.py` 读入原版 `X-Ray Mirror.html`，输出一个在慢机器上也跟得上摄像头的版本。解剖数据和画面效果不变：
“Best picture” 档渲染出来的画面与原版逐像素相同。

```bash
python3 patch.py "X-Ray Mirror.html" "out/X-Ray Mirror (fast).html"
```

成品文件不入库。原作没有许可证，这个仓库又是公开的，所以这里只放补丁脚本；生成的文件请仅自用，
要公开分发需先取得原作者同意。

## 原版为什么卡

三个原因都是实测出来的（无显卡的 4 核沙箱，软件渲染）。

| 原因 | 实测 |
|---|---|
| 手部追踪器每一帧都跑。画面里没有手时，它每帧都在整幅画面里找手 | CPU 上找一次手 60–86 ms，脸部追踪一次 21 ms |
| 没有显卡时，追踪器的“GPU 版”由软件模拟 | 原版 97% 的主线程时间在等它的结果，每帧约 0.8 秒 |
| 手部暗影每帧做一次画布高斯模糊 | 无显卡时每只手每帧约 80 ms |

第一条对所有机器都成立：没举手的大部分时间里，原版把大半算力花在找一只不存在的手上。

## 改了什么

1. **手部追踪的调度。** 没有手时每秒只找几次；有手时按机器能力决定隔几帧跟一次，
   并且放到两个摄像头帧之间的空档里做，不拖慢下一帧。
2. **自动画质。** 3D 图层的清晰度有 7 档，手部追踪频率有 4 档（最后两档只跟一只手，开销减半），
   按实际帧率自动升降。降清晰度没有换来帧率时会撤回。右侧新增 Performance 面板，显示当前状态，也可以手动固定。
3. **没有显卡时的专门处理。** 追踪器改用 CPU 版，只看一份缩小的画面，摄像头改要 640×360，
   并在面板里提示打开浏览器的硬件加速。
4. **更便宜的绘制。** 手部暗影不再走画布模糊，只画手所在的那一块；样式没变时不重设；
   双显卡电脑上请求使用独立显卡。
5. **平滑改为按时间计算**，帧率变化时手感不变。
6. **顺手修了一个 bug：** 左右手标签原来是反的。

## 实测结果

同一沙箱（无显卡，4 核），摄像头用一张静止的样例照片代替。

| 场景 | 原版 | 优化版（Automatic） | 优化版（Best picture） |
|---|---|---|---|
| 实时，没举手 | 1.2 帧/秒 | 10.1 帧/秒 | 5.0 帧/秒 |
| 实时，举着一只手 | 1.1 帧/秒 | 7.9 帧/秒 | 3.3 帧/秒 |
| 只画 3D 图层（演示场景，默认图层） | 6.1 帧/秒 | 20.7 帧/秒 | 与原版相同 |

追踪结果（脸部点数、姿态角、二维修正量）与原版一致，网络请求仍是同样的 8 个下载。

## 没验证的

**有显卡的机器上能快多少，我没有数据。** 这个沙箱没有显卡，上面的数字是最差情况下的提升。
在有显卡的机器上，收益主要来自第 1、2 条，幅度取决于机器。
如果仍然卡，请勾选 “Show tracking data”，把 speed、sharpness、face tracker、hand tracker、graphics 这几行的内容发给我。
