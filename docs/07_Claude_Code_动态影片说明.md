# 07 · Claude Code 动态影片：《7 路 / Route 7》代码版

这是整支片的"代码版"：1920×1080、30 fps、60.0 秒。每一帧画面、每一个声音都由 `film/` 里的代码确定性地生成，没有使用任何 AI 生成的图片或视频。它和 `01`–`06` 的实拍/生成版共用同一份主剧本（`master.json`）、同一套时间码和同一套 UI，可以当作成片级动态分镜（animatic），也可以直接作为最终片里的 Motion Graphic 与 Screen UI 层。

## 素材只有三类

1. **客户产品图**：Gateway 正/背、Paragon Outdoor 正/背、Portal 32/43/55，全部从规格单上抠像。背景复杂的银色机身用了点提示 SAM，黑色机身用亮度蒙版，底座和阴影单独处理。每台设备的屏幕四角都由图像分析测得（`assets/cut/screens.json`），UI 通过单应矩阵（CSS `matrix3d`）贴进真实屏幕的真实透视。
2. **Lyra 的两张全身照**（白底/黑底）和它们的抠像。
3. **代码**：环境、人物剪影、字条、卷帘牌、城市、字体、UI、声音全部由代码生成。

## 系统（`film/src`）

- `engine.js`：时间轴、命名缓动（glide / settle / cine / crane / push / exit / snap）、单调三次样条、单应矩阵、种子随机。
- `devices.js`、`space.js`：真实尺寸的设备、屏幕透视贴图、2.5D 摄影机（F = 1150，薄透镜景深）、接触阴影、抛光地面反射、屏幕辉光、Portal 墙晕、`frameScreen`（屏幕锚定构图，用于中心锁定与匹配剪辑）。
- `ui.js`：Lyra OS（状态栏、在场呼吸点、语音线、字幕胶囊、卡片、路线图、让出空间 makeRoom、Handoff slide）。
- `env.js`、`city.js`：3D 点光源焦外光斑（光斑大小由弥散圆决定，能量守恒）、雨、城市光图、体育场、节点。
- `route7.js`：站牌字卡、双字体字幕、16mm 模块、卷帘牌、铅笔字条、翻盖手机、钟楼、split-flap、织物、人物剪影。
- `s1_human.js` … `s5_final.js`：五幕。

## 声音（`film/audio`）

`synth.py`（从零合成的乐器与拟音）加 `route7_score.py`（逐帧对齐的总谱）。120 BPM，E 调，调性来自 1980 年代公交下车铃基频 E6。

- 0–1.5 秒是单声道、带磁带嘶声的 1985 年：柴油怠速、踩在网格上的转向灯、卷帘滚动，停在「7」时是一声机械「咔」。这一段不用铃，第一声「叮」留到 25.5。
- 1.5–10 秒只有低而稀的毛毡钢琴（E3，然后 B2、G2），8.5 秒以后止音，给「May I?」留出空拍。
- Lyra 的"声音"是三音玻璃钟动机；铅笔字变印刷体的「嗒」是木质活字声，不用电子提示音。
- 28–42 秒是半速有机律动：底鼓 1、2&、4&，拍手和刷鼓在 3。37.5 秒她低声哼出四个音，39.0 秒远处体育场亮灯时有一声闷响。
- 42–46 秒对白期间只留底鼓（1、3 拍）、人群拍手和雨；46 秒起换成切分全速（1、2&、3、4&，从不做四拍底鼓），Bass 十六分。
- 51.75–52.0 秒整片静默 0.25 秒，接着 52.0 秒 E 大调绽放。
- 57.0 秒音乐在 0.15 秒内退下，只剩雨声；Sonic Logo 是"叮—叮"：E6 公交铃加 B6 玻璃钢铃，外加 40 Hz 低频。

成片用两遍 EBU R128 响度归一到 −14 LUFS，真峰值低于 −1 dBTP，响度范围约 10 LU。最响的是 46–52 秒的城市段，最安静的是 1985 年之后的换乘大厅。

## 复现

```bash
pip install numpy scipy pillow imageio-ffmpeg numba
cd film
node render.mjs --video --workers 3            # 画面 → out/film_silent.mp4（可用 --from / --to 只重渲一段）
python3 audio/route7_score.py ../out/score.wav # 声音
python3 finish.py                              # 混合：master / X / web 三个版本
```

## 代码版与 master 的时间差异

代码版是先于 master 定稿剪出的独立版本。大多数时间码与 master 一致：25.5 第一声铃，28.0、30.0、42.0、47.0–51.0 各站的铃，46.5 背面与卷帘倒翻，52.0 进场。以下几处按代码版自己的画面节奏保留：

| 项 | master | 代码版 |
|---|---|---|
| 七声节点铃 | 53.5 起每 0.5 s，01 先闻其声 | 55.25 起每 0.25 s，500 m 高度七站同时在画内 |
| End Card | 交叉 57.5 · LIVEX.AI 58.0 · AI City 58.5 · Ask the city. 59.0 | 57.9 · 58.2 · 58.6 · 59.1 |
| 站牌字卡 | top 940，主行 22 px | top 912，主行 21 px |
| 字幕 | y 940，人与 Lyra 都是 46 px | y 858（近景 968 / 972），人 50 px、Lyra 40 px |
| S03 导向牌 | 全部虚焦、不写字 | 对焦 1 秒，读得出 Exit A / Exit B / Stadium · Gate C，但没有 Harbour Depot |
| 片尾小字 | 无 | 有一行 spec film 署名（见下） |

要让代码版逐项对齐 master，按 `05` §13 与 `06` 附录 B 的清单修改后重渲即可。

## 代码版与实拍/生成版的区别

- 代码版没有真人表演。陈师傅由剪影、红围巾、字条、字幕和声音代表；Lyra 是静态照片，只有呼吸、缩放和侧移，所以镜像指向、步行、手势都由 UI 箭头和 Handoff 滑动替代。
- 1985 年的手握方向盘在代码版里换成了卷帘牌：钩子依然是"7"的时空匹配剪辑。
- 林在草坪上拍胸口的镜头，代码版不表现，由举起的字条和"Last stop"字卡承载。
- 片尾有一行小字说明：这是一支 spec film，画面、UI、动效与声音全部由 Claude 用代码生成。要去掉它，删除 `s5_final.js` 中的 `this.credit` 即可。
