## 【使用方法】

#### 1. 这些图的用途与两个版本

- **分镜展示**：给客户和团队看的 Storyboard。
- **Seedance 2.5 I2V 的首帧与尾帧**：视频模型只负责摄影机和人物运动，设备保持静止。Seedance 的输入一律用下表的 **PLATE 底板版**；画面里没有设备屏幕的镜头（S01–S04、S12、S16 等）直接用关键帧本身。
- **合成底板**：后期对生成素材里的屏幕**逐镜**做平面追踪，贴入单独生成的 Lyra 素材和 Claude Code 渲染的 UI（第 5 节）。

所以每张带设备屏幕的镜头都要出两个版本：

| 版本 | 屏幕里放什么 | 用途 | 文件名 |
|---|---|---|---|
| **A 展示版** | 按参考图画出的 Lyra。UI 只画**无字的形状占位**：顶部一条细状态栏，下部一张圆角卡片，一条钴蓝细线或箭头 | 分镜展示、审片；**不进 Seedance** | `KF-Sxx.png` |
| **PLATE 底板版** | 按屏幕模式生成（第 5 节）。**浅色模式**（Gateway、日间 Portal）= 均匀发光的**浅灰白**，线性光约为成片 UI 白 `--paper` #f4f5f7 的 85%（sRGB 约 #e3e4e6），保留 3–5% 玻璃反光，并且像真屏幕一样给面前的人、字条和地面打冷白光、在抛光地面上留下屏幕倒影。**深色模式**（Paragon、医院夜间 Portal）= **纯黑** #000000，只保留极淡的玻璃反光。两种都不画 Lyra、不画 UI、不写字 | **Seedance 首帧 / 尾帧**、后期贴屏 | `KF-Sxx-PLATE.png` |

> 为什么浅色模式不用纯黑：S09 里屏幕是陈师傅身上的主光，S11 里屏幕在她身侧勾出冷边。黑屏不会给她的脸、字条和水磨石打冷白光，也不会在地上映出屏幕倒影；成片贴上白底 Lyra 以后，光照和倒影对不上，一眼就是合成。浅灰白的线性光比成片 UI 白低约 15%，贴屏后 UI 仍是画面里最亮的一块；藏蓝大衣、黑发、玳瑁镜框都比它暗，抠遮挡物反而更稳。

#### 3. 操作顺序：在同一对话里锁定一致性

1. **新建对话**，选择 GPT-image-2.5 图像生成。第一条消息上传图 1–5，并粘贴这句：「以下 5 张是本项目的权威参考图，编号为图 1 gateway_sheet、图 2 paragon_sheet、图 3 portal_sheet、图 4 lyra_white、图 5 lyra_black。产品只参考实物外观，不要把规格文字带进画面。请确认编号，暂不生成图片。」
2. **粘贴【全局前缀】**：复制下文「【全局前缀·开始】」到「【全局前缀·结束】」之间的全部内容，作为第二条消息发送，并要求它确认、暂不生成。
3. **生成陈玉珍角色设定板**：粘贴下文第 7 节的提示词。满意后回复「锁定这张为图 6，之后所有镜头里的陈玉珍都必须与图 6 一致」。不满意就用局部编辑修，不要整张重来太多次，否则脸会漂。锁定后按【附录】D.2 出两张光照版（CS-CHEN-A 站厅冷白、CS-CHEN-B 广场蓝调雨夜）和一张道具板。
4. **生成手部设定板**：粘贴第 8 节提示词，锁定为图 7（= CS-HANDS）。需要林时，再用第 9 节提示词生成图 8（= CS-LIN）。
5. **锁定 Lyra 姿态帧（防漂移）**：Lyra 是全片一致性风险最高的角色。所有 LYRA-… 姿态帧只从图 4 / 图 5 编辑而来，规则三条：① 只用**选区重绘**改手臂、腿和躯干朝向，脸和头发永远不进选区；② 定稿后把原图（lyra_white / lyra_black）的脸和头发像素贴回、边缘羽化融合（头部角度改变的帧改做面部叠图比对）；③ 逐张过【附录】D.4 的 Lyra 验收项。出现左右镜像（X 标跑到右胸、发侧对调）的整张作废。建议最先出 LYRA-POINT-9x16（全片唯一的指向母版，见全局前缀【Lyra 圣经】和附录 D.3 S09）。
6. **按推荐顺序出镜头**：S09 → S03 → S04 → S05 → S06 → S01 → S02 → S10 → S11 → S12 → S14 → S15 → S16 → S17。先出 S09（Hero），换乘大厅和 Gateway 的样子就定下来了，S03–S06 再把 S09 定稿作为环境参考。每条镜头提示词开头的【参考图】列出了该镜要用的图，**发送时把这些图重新附在同一条消息里**，一致性会明显更好。**每镜定稿后，紧接着出该镜的 PLATE 和附录 D.3 里列在该镜名下的派生帧**（同一对话、同一批参考图），再进入下一镜。
7. **每张先出 A 展示版**，满意后回复「锁定为 KF-S0X」。再回复该镜提示词里写好的「S0X PLATE」，生成底板版。镜头里写了「变体」的，回复对应口令即可生成。
8. **局部修改用编辑，不要整图重画**。话术：「保持构图、人物、光线、产品完全不变，只把 ___ 改成 ___。」产品细节（脚轮、顶棚立柱、摄像头模组）或手指、戒指位置出错时，用选区重绘，并在同一条消息里重新附上对应的产品图或图 6 / 图 7。
9. **出现漂移就重开对话**：单个对话超过约 25 张，或者陈玉珍、Lyra 的脸开始漂，就新开对话，重新上传图 1–7，重新粘贴全局前缀，再附上已定稿的 S09 和 LYRA-POINT-9x16 作为环境与身份参考。
10. **命名与存放**：保存到 `out/stills/`，**文件名直接用 04 的代号**：展示版 `KF-S09.png`，底板版 `KF-S09-PLATE.png`，派生帧 `KF-S09-SEAM-PLATE.png`、`LYRA-POINT-9x16.png`，设定板 `CS-CHEN-A.png`、`CS-HANDS.png` 等。03 里的「主帧 / 变体 / PLATE」与 04 代号的一一对应见【附录】D.1；底板代号一律以 `-PLATE` 结尾。

#### 4. 画幅：16:9 主版，4:5 X 版

- 每条提示词都已写明 16:9。界面有尺寸选项时，选横幅 16:9，优先 2048×1152 或更高。
- 如果只能输出 3:2 横幅（1536×1024），在提示词末尾加一句「主体与关键元素全部落在中央 16:9 区域内，上下各留约 8% 可裁边」，后期裁成 16:9。
- **X 版 4:5（1080×1350）默认从 16:9 主版中心裁切**：取中央 864 px 安全列（1920 宽画面中的 x 528–1392，即画宽 27.5%–72.5%）放大 1.25 倍；有摄影机运动的镜头允许 ±200 px 的水平重构偏移（05 §1.2.1）。
- **例外：S01、S02、S18 按 05 §1.2.4 原生重排，不是裁切**。S01 的 4:5 版是居中的 4:3 窗口，只取源图约 900×675 的区域；S02 的字条在 16:9 里宽 62%（约 1190 px），比安全列还宽，所以另出一张竖幅（S02 V = KF-S02-V，字条约占 4:5 画宽 90%，供 04 的 J02-V 用）；S18 是代码渲染的 End Card。
- **硬规则：产品与反转要素必须在安全列内。** 产品 = 该镜里被介绍的 Gateway / Portal / Paragon 整机与屏幕；反转要素 = 让观众「看懂」的那个东西：S04 的 LED 竖光、S09 沿手指方向的 Exit B 暖光、S11 零售场景唯一的 Gateway、S14 的 Paragon 回答画面、S17 的七个节点与体育场。每条提示词都写了具体坐标。唯一的例外是 S04 的竖光：16:9 里它必须贴画面左缘，4:5 版单独处理（见 S04）。
- 人物的脸、Lyra 的双眼、设备屏幕同样尽量落在安全列里；画面左下角（站牌字卡位）和下方中央（字幕位）保持简洁。
- S01 是 1985 年的 16mm 段落，后期会加 4:3 遮幅。构图按中央 4:3 区域来做，左右各约 12.5% 不放关键内容。

#### 6. 文字一律不让模型写

以下文字全部由后期代码渲染贴入。GPT-image 只负责留出位置，画面里不生成任何可读文字：

- 屏幕 UI：状态栏、卡片标题、数字、按钮、开关。
- 影片层：站牌字卡 StopCard（左下角 x 96 / y 940）、箭头卡、年份角标（1985 / 2026）、字幕（y 940 居中）、节点标签。
- 道具：字条上的铅笔手写（请真实年轻人手写后扫描）、翻盖机外屏（生成一律为黑，亮屏和消息都后期合成）、球衣号码、座位号。
- 环境：导向牌只保留箭头与图形，并且虚焦。
- 设定板：身高刻度只画无字细线，数字后期标注。

唯一例外是 S01 挡风玻璃上的卷帘牌镜像反光。可以尝试让模型写「7 HARBOUR DEPOT」；写不准就留一条无字的反光带，后期贴字。

#### 7. 陈玉珍角色设定板提示词（生成后锁定为图 6）
