为什么选它：最终选定《7 路》。 1. 它是唯一从战略层面回答客户核心那句话的方案：「LiveX 不是 AI City 里摆放的设备，设备本身就是构成 AI City 的节点。」城市本来就是一张网络，由站台、线路和问路的人组成。旧站台靠人回答问题，新站台就是 LiveX 节点。这样 PERSON → AI → LIVEX → PLACE → NETWORK → AI CITY 这条尺度阶梯自然成立，NETWORK 也不需要画一根线。 2. 评审共识：三位评审各自的前三名里，只有《7 路》和《第一位听众》同时出现在全部三份名单中。《第一位听众》的平均分最高（85.7），但它最核心的两个画面恰好压在 AI 视频最弱的地方：屏幕里 Lyra 的连续步行，和真人拉大提琴。它的情绪赌注也最低，品牌句最弱。所以我们只把它最好的手法 The Handoff 嫁接进来。 3. 和真实交付物匹配：这支片最终要由 Claude Code 逐帧渲染成 60 秒的动态影片，发布在 X 上。《7 路》的每一个核心装置都是代码的原生语法：铅笔字变印刷体、站牌字卡、卷帘翻牌、铃声驱动节点点亮、两笔画出 X。只用现有的静态 Lyra 抠图和产品抠图，就能做到电影级；现有引擎里的 Space、LyraScreen、PlaceShot、City、EndCard 可以直接复用。 4. 差异化：本轮 12 个方案里，4 个在赶去看新生儿，4 个用手机电量耗尽开场，还有好几个依赖「被 AI 认出来」。《7 路》全部避开了。Lyra 懂的是城市的历史，而不是这个人的脸。它还是唯一一个把尊严还给老人、并让老人也去帮助别人的方案。 5. 品牌资产：「Ask the city.」让 LiveX 占住一个动词。一声公交铃同时承担结构、调性和 Sonic Logo，品牌可以长期拥有它。 6. 短板已修：站号逻辑现在正好 7 站，以「07 · Last stop」收尾；符号做了减法；陈师傅不再是「无助老人」；节点光形在前 45 秒系统地教给观众；产品角色各归其位。精修版都已处理。 《初次见面》的镜像托抱是本轮最强的单个 Hero 画面，它最好的想法（两笔交叉成 X）也已嫁接进来。

嫁接进来的想法：1. The Handoff，来自 STRANGER2《第一位听众》：27–42 秒每响一声「叮」，Lyra 就从上一台屏幕的左边框走出，再从下一台屏幕的右边框走进来，依次经过换乘大厅的 Gateway、Exit B 的 Portal、Market Hall 的 Gateway。原稿靠字卡说明「这是同一个 Lyra」，现在靠她的动作来证明。 2. Center-Lock 和双字体系统，来自 FORMAL1《静点》：47–50 秒上游四站的蒙太奇，每一格里 Lyra 的双眼都注册在画面同一坐标上。地点在变，她不动，所以 0.8 秒一格也认得出是同一个 Lyra。人说的话用 Instrument Serif 斜体，Lyra 和 UI 用 Geist，两套字体就是两种声音。Lyra 的近讲干声和站厅的长混响形成对比，这是留给耳朵的伏笔。 3. 两道弧线交叉成 X，来自 INTIMATE1《初次见面》：这里改写成一笔属于人、一笔属于 AI。第一笔是字条上划在 Seat 7 下面的那道铅笔线，第二笔是 Lyra 路线卡上的钴蓝路线。两条路线交叉，成为 LiveX 的 X，品牌符号在最后一秒被重新解释：她的路和 Lyra 的路。 4. 指向即现实，来自 RELAY2《同一分钟》：Lyra 在屏幕里指向画右，Reveal 拉开后，真实的 Exit B 扶梯正好在那个方向亮着。屏幕里的空间和真实建筑对上了，这是 Physical AI 最准的一个细节。 5. 安静的一拍，来自 FORMAL2《你在这里》：在 01 · St. Mary's 的医院走廊里，Lyra 把食指轻放在唇前，UI 显示「Quiet volume」。一拍就证明她懂语境。 6. 节点只靠产品自己的光被认出、机身背面就是品牌，来自 WILDCARD1《守夜灯》和 RELAY1《交接》：前 45 秒系统地教观众认三种光形（Gateway 是两道白色竖条，Portal 是一圈蓝晕，Paragon 是上下两块白色矩形）。结尾航拍先在 100 m 高度停 1.2 秒，让光形能被认出来。广场上 Paragon 背面发光的 X，是品牌第一次以真实机身出现。 7. 按评审 1 的修正落实：站号正好 7 站，以「Last stop」收尾；零售场景改用 Gateway，Portal 只放在过渡空间；Gateway 里的 Lyra 统一为 1:1 真人等身；陈师傅主动给迷路的球迷指路，而不是被救助的人；删掉搪瓷徽章，符号只留字条、红围巾、钟楼和三个 7。按评审 3 的修正落实：4:5 安全区，1985 年段落延长，字条在手机上一眼可读。

《7 路》

【人 00–10】1985 年，16mm 胶片里一双年轻的手把巨大的方向盘向右打满，车顶卷帘牌「rrrrt—咔」停在「7 HARBOUR DEPOT」。硬切：同一个「7」变成 2026 年一张铅笔字条上的「Seat 7」——「奶奶 — Gate C · 114 · Row 12 · Seat 7 · 19:30 ♡ 林」。陈玉珍 72 岁，开了 31 年 7 路，今晚一个人去看孙女首秀。儿子发来「Mum, I'll come get you?」，她「啪」地合上翻盖手机。扶梯把她送进 Harbour Line 的新换乘大厅：白色清水混凝土柱廊、四种语言的导向牌，没有一个旧站名。她在柱旁停下展开字条，手在抖。画面左缘一团冷白竖光，画外一句贴近耳边的「May I?」。

【AI 10–20】一个穿白色立领针织衫的年轻女人探身看字条。陈师傅嘟囔：「They built a stadium on my bus depot.」对方答：「Route 7's last stop. I know it.」有人记得她的总站。她愣住，笑出一声，像当年乘客给她看月票那样把字条举高；镜片反光里铅笔字逐个变成印刷体，路线卡滑过，「Step-free route」已被点亮——她没开口要。

【LiveX 20–27】一镜到底后拉：Lyra 的眼睛 → 全身 → 屏幕边框 → 2.18 m 的 LiveX Gateway（顶梁、摄像头、两条白色 LED 竖灯条与水磨石上的倒影、底板与脚轮）→ 围红围巾、举着字条的 1.58 m 的陈师傅 → 30 m 柱廊。人潮带着拖影绕流，只有她们不动。25.5 秒第一声 1980 年代公交下车铃「叮」，字卡「05 · Harbour Interchange」。沿路线所指，真实的 Exit B 扶梯亮着暖光。

【旅程 27–42】每一声「叮」，Lyra 从一块屏幕左边框离开、从下一块屏幕右边框进来：白墙通道里的 Portal（→ Exit B），旧菜市场改成的 Market Hall 里的 Gateway（06）。她买下最后三条之一的 7 号主场围巾，叠在自己织的红围巾上。迷路的外国球迷问「Gate C?」，她脱口而出「Past the clock tower. Follow the scarves.」——31 年的反射还在。条纹围巾越来越多，门一开，风、雨和齐唱涌进来。

【城市 42–52】「叮」07 · Harbour Depot。蓝调细雨，1978 年红砖钟楼是旧总站唯一的遗存，旁边立着 Paragon Outdoor。她手掌贴砖：「I drove this route for thirty years.」Lyra：「Then you know the way.」她挺直背汇入人潮。摄影机绕到 Paragon 背面：发光的 X 与 LIVEX.AI。字卡「rrrrt」倒翻回 01——同一分钟，上游四站都在为这场比赛运转：St. Mary's、Western Univ、Harbour Hotel、Pier Tower，每格都是同一个 Lyra，双眼在同一位置。「→ Gate C」，闸机咔嗒，球场轰鸣。

【AI City 52–60】12 排 7 号，她坐下，字卡翻成「07 · Last stop」。草坪上的林在人海里找到一张举高的白纸和一点红，笑着拍两下胸口的 7。音乐抽空，远处一声铃。摄影机升起：100 m，四台 Paragon 的灯箱像表盘刻度；500 m，七声铃由远及近点亮旧 7 路七站，一根线都不画；然后数百个节点静静亮起。黑场，一笔铅笔、一笔钴蓝交叉成 LiveX 的 X。LIVEX.AI。AI City。Ask the city.

07 · Claude Code 动态影片：《7 路 / Route 7》代码版

这是整支片的"代码版"：1920×1080、30 fps、60.0 秒。每一帧画面、每一个声音都由 film/ 里的代码确定性地生成，没有使用任何 AI 生成的图片或视频。它和 01–06 的实拍/生成版共用同一份主剧本（master.json）、同一套时间码和同一套 UI，可以当作成片级动态分镜（animatic），也可以直接作为最终片里的 Motion Graphic 与 Screen UI 层。

素材只有三类

  1. 客户产品图：Gateway 正/背、Paragon Outdoor 正/背、Portal 32/43/55，全部从规格单上抠像。背景复杂的银色机身用了点提示 SAM，黑色机身用亮度蒙版，底座和阴影单独处理。每台设备的屏幕四角都由图像分析测得（assets/cut/screens.json），UI 通过单应矩阵（CSS matrix3d）贴进真实屏幕的真实透视。
  2. Lyra 的两张全身照（白底/黑底）和它们的抠像。
  3. 代码：环境、人物剪影、字条、卷帘牌、城市、字体、UI、声音全部由代码生成。

系统（film/src）

  • engine.js：时间轴、命名缓动（glide / settle / cine / crane / push / exit / snap）、单调三次样条、单应矩阵、种子随机。
  • devices.js、space.js：真实尺寸的设备、屏幕透视贴图、2.5D 摄影机（F = 1150，薄透镜景深）、接触阴影、抛光地面反射、屏幕辉光、Portal 墙晕、frameScreen（屏幕锚定构图，用于中心锁定与匹配剪辑）。
  • ui.js：Lyra OS（状态栏、在场呼吸点、语音线、字幕胶囊、卡片、路线图、让出空间 makeRoom、Handoff slide）。
  • env.js、city.js：3D 点光源焦外光斑（光斑大小由弥散圆决定，能量守恒）、雨、城市光图、体育场、节点。

声音（film/audio）

synth.py（从零合成的乐器与拟音）加 route7_score.py（逐帧对齐的总谱）。120 BPM，E 调，调性来自 1980 年代公交下车铃基频 E6。0–1.5 秒是单声道、带磁带嘶声的 1985 年；Lyra 的"声音"是三音玻璃钟动机；Sonic Logo 是"叮—叮"：E6 公交铃加 B6 玻璃钢铃，外加 40 Hz 低频。成片用两遍 EBU R128 响度归一到 -14 LUFS / -1 dBTP。
