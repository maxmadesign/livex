## 1. 声音总纲：一声铃

### 1.1 一句话

**整部片的声音只建立在一件东西上：一台 1980 年代公交车的下车铃。** 它同时做三件事：当转场声（每到一站「叮」一声），定全片调性（配乐以 E 为主音），也是 Sonic Logo 的原型。公交下车铃本来的意思就是乘客在「提问」——按下它，是在对司机说「我要在这里下」。三十一年里，陈师傅每天听这个声音几百次。今晚按铃的是她，回答她的是城市。**Ask the city.**

### 1.2 五条声音规则

| # | 规则 | 落到哪里 |
|---|---|---|
| 1 | **一声铃 = 结构。** 全片 18 声「叮」全部落在 0.5 s 拍点上，每一声对应一个站、一个节点或 Logo 的一笔。1985 段不用铃，第一声留给 25.5。 | §6.1 |
| 2 | **两种声学 = 两种存在。** Lyra 是近讲干声，没有任何空间；世界里的人带着真实空间的混响（站厅 3 s、连廊 1.8 s、广场 1.2 s）。直到 20–27 s 后拉，Lyra 的动机才第一次「长出」站厅的混响——声音上的 Reveal。 | §8 |
| 3 | **同一颗铃，不同房间。** 站点铃永远是同一个 E6 录音，但每一站都在当地的声学里响：站厅、通道、铁骨玻璃顶、雨夜广场、医院走廊、酒店大堂……这就是 *Same AI. Different places.* 的声音版本。 | §6.2 |
| 4 | **UI 只用真实材料。** 纸、木、玻璃。没有正弦提示音，没有合成器 blip，设备本身不发任何电子音。UI 音全部压在 −18 LUFS 以下，从不盖过人声。 | §5 |
| 5 | **城市自己在演奏。** 42 s 以后，鼓组的主干是体育场外球迷整齐的拍手（实录，120 BPM）；雨打不锈钢顶棚是踩镲；七声节点铃沿旧 7 路依次响起，就是结尾的旋律。 | §2.6、§3 |

### 1.3 尺度阶梯 × 声音

| 尺度 | 时间 | 声音签名 |
|---|---|---|
| PERSON | 00.0–10.0 | 贴近的声音：呼吸、纸、翻盖机「啪」、她的鞋底。钢琴只剩单音。1985 年是单声道。 |
| AI | 10.0–20.0 | 一个没有混响的声音出现在有混响的世界里；三音玻璃动机第一次出现。 |
| LIVEX | 20.0–27.0 | Boom、宽 Pad、直立贝斯、35 Hz 次声；Lyra 动机的尾音长出 3 s 站厅混响；25.5 第一声铃。 |
| PLACE | 27.0–47.0 | 每一站一声铃、一种声学；半速有机律动；门一开，城市涌进来。 |
| NETWORK | 47.0–52.0 | 同一分钟、四个地点：整秒一声铃 + 4 帧真实环境声。 |
| AI CITY | 52.0–60.0 | 全体抽空 → 七声铃沿 E 大调五声音阶上行 → 数百颗玻璃颗粒 → 黑场里「叮—叮」。 |

### 1.4 禁区（反 EDM、反企业配乐）

**不做 EDM：**
- 不用四拍底鼓（four-on-the-floor）。全速段的底鼓是切分型 1、2&、3、4&，节奏的主干是拍手、刷鼓和直立贝斯。
- 不做 build-up → drop。本片的「drop」是反过来的：53.0 所有乐器抽空，只剩风声和一位老人的哼唱。
- 侧链只做「听不见的呼吸」，增益衰减 ≤ 2 dB，不做泵感。
- 不用 supersaw 主音、pluck 琶音、军鼓滚奏、白噪声扫频 drop、vocal chop。
- 滤波逐小节打开只作用在 Pad 的音色上（从暗到暖），不作用在主旋律上。
- 所有律动乐器带人手微时值（±6 ms）和 54% 摇摆，力度随机 ±15%。

**不做传统企业配乐：**
- 不用尤克里里、钟琴加口哨式的「乐观」，不用弦乐大齐奏的「励志」，不用 I–V–vi–IV 流行进行。
- 不用钢琴分解和弦铺满全片；钢琴只在人物需要的时候出现，旅程段完全退场。
- 不用 stadium-rock 式的鼓点推进；高潮靠声学空间和调式转换，不靠堆音量。
- 不用库存音乐、库存 Logo 音效、任何真实俱乐部的队歌或助威曲。

**其他禁区：** 不用 vocoder、机器人声或电话 EQ 处理 Lyra；不拿口音做笑点；不给设备加开机音、提示音或电流声；1985 段不用铃。

## 2. Background Music 配乐

### 2.1 风格定位

**Electronic + organic 的现代配乐**：新古典的毛毡钢琴与直立贝斯、刷鼓、木鱼、真实人群拍手、一位年长女性的无词哼唱，放在温暖的模拟合成 Pad、FM 玻璃钟、35 Hz 列车次声和颗粒化站厅广播之上。听感像一部欧洲文艺片的原声遇上一台温暖的模拟合成器：低频充足，节奏有变化，情绪克制，没有一个音在「卖」产品。

- **有机层是人**：陈师傅的哼唱、直立贝斯、刷鼓、球迷的手掌、公交铃。
- **电子层是城市和 Lyra**：地铁次声、站厅广播纹理、Pad、FM 玻璃钟（Lyra 的声音）。
- 两层的比例跟着尺度走：00–20 s 有机为主，20–42 s 电子层托起空间，42–52 s 城市的实录声成为打击乐，52 s 以后两层合一。

### 2.2 速度与网格：120 BPM，半速 → 全速

| 项 | 规格 |
|---|---|
| 速度 | 全片锁定 120 BPM，4/4。一拍 0.5 s（15 帧），一小节 2.0 s（60 帧），全片 30 小节。速度从不改变，改变的只是律动的体感。 |
| 00.0–42.0 | **半速体感（60）**。重音（刷鼓 / 拍手）落在每小节第 3 拍，也就是每 2 s 一次。10–20 s 的「心跳式 Sub」落在第 1、3 拍，每秒一次，正好是 60 BPM 的静息心率。 |
| 42.0–60.0 | **全速（120）**。42.0 进入广场，球迷的拍手落在第 2、4 拍，每秒一次反拍，城市把速度「翻倍」交还给她。 |
| 网格规则 | 所有「叮」、字卡、主要转场都在 0.5 s 的整数倍上；八分后半拍（x.25 / x.75）的声音按样本精确放置，画面取最近一帧（最大偏差 17 ms，音频超前，在 EBU R37 容差内）。 |
| 1985 段 | 无配乐。转向灯继电器落在 0.0 / 0.5 / 1.0，四分音符，全片的节拍器从这里起步。 |

### 2.3 调性与和声弧线：E 小调 → E 大调

**调性来源**：公交铃基频 E6。全片以 E 为主音；00–52 s 为 E 小调（以 Aeolian 为主，C♮ 代表「迷路」；D 和弦上出现 C♯ 的 Dorian 亮色，代表「找回节奏」）；52.0 转入 E 大调（Emaj9 绽放）；58.0 的 Sonic Logo 落在空五度 E–B 上，58.5 的大调动机用 G♯ 把它确认成大调。

**三个关键音程**（和声弧线的「剧情」）：

1. **G♮ → G♯**：小三度变大三度。12.5 的 Lyra 动机是 G5–B5–E6（小调），58.5 的收尾是 G♯5–B5–E6（大调）。同一个动机，只改一个音。
2. **A → G♯**：37.5–41.0 陈师傅的哼唱停在 A4 上，悬在 B7 和弦里当属七音，整整 14 秒没有解决；53.0 她唱出 G♯4，再落到 E4。这支歌在全片里只唱完一次。
3. **两次 B7**：第 21 小节的 B7 走向 42.0 的 E **小调**（假解决：到了旧总站，还没到家）；第 26 小节的 B7 走向 52.0 的 E **大调**（真解决：孙女在草坪上看见了她）。

### 2.6 分段编配

#### Prologue · 1985（0.0–1.5，第 1 小节前三拍）——无配乐

- 单声道。所有 1985 声音在 `era` 总线上求和成 mono，带通 180–6 500 Hz，tanh 饱和（驱动 1.6），磁带嘶声（高通 4 kHz，−45 dBFS），◇ 轻微抖晃（wow 0.25% @ 0.6 Hz + flutter 0.08% @ 7 Hz）。
- 柴油怠速（24 Hz 点火脉动，1–8 次谐波，低通 500 Hz）是唯一的「低音」。
- 转向灯继电器「哒」落在 0.0 / 0.5 / 1.0（◆ 四分音符），◇ 继电器回位的「嗒」落在 0.25 / 0.75 / 1.25，低 6 dB。
- 卷帘摇柄「rrrrt」0.0–0.9，0.9「咔」定位（◆）。
- **不用铃，不用任何乐音。** 1985 年只有机器和手。

#### A 段（1.5–10.0，第 1 小节第 4 拍 – 第 5 小节）——极简，约 −21 LUFS（A-2 −20）

- ◆ 1.5 毛毡钢琴 **E3** 单音，力度 0.45，同帧 ◆ **E1** 低频长音淡入（attack 2.5 s，vol 0.12）。这是 2026 年的第一个音。
- ◆ 4.5 **B2**（落在合盖「啪」的同一拍）· ◇ 6.0 **G2** · ◇ 7.5 **B2**（动作剪辑）· ◇ 8.0 **G2**（最后一个音）。钢琴只用 B2、G2 两个音（◆），像她在人潮里来回找的两个方向。
- ◆ 8.5 钢琴止音（◇ 制音器落下的一声轻响，−38 dBFS），8.5–9.0 空拍：音乐、站厅底噪同时降 3 dB，把耳朵清空给「May I?」。
- 画内低频：1.5–4.5 车厢 35 Hz；4.5–7.5 列车离站 35 Hz 次声。E1 长音一直在下面。
- 没有鼓、没有 Pad。

#### B 段（10.0–20.0，第 6–10 小节）——Lyra，被读懂

- ◆ 12.5 **Lyra 动机首次出现**：G5（12.5）· B5（12.625）· E6（12.75），FM 玻璃钟，**干声**（◇ 混响送量 0，和 Lyra 的人声保持同一种「没有空间」）。刻意留给被读懂的这一句。
- ◇ 14.0 Pad 转 **Cmaj7**；◇ 14.5 钢琴 B3 + E4 双音（她笑出一声之后，Cmaj7 上的七音和三音，温柔的悬置）。钢琴不在任何台词下面出现。

#### C 段（20.0–28.0，第 11–14 小节）——Reveal，漂浮，无鼓

## 3. Environment 环境声

### 3.1 原则

1. **每个地点一个声学签名**，混响时间（RT60）和早期反射按真实空间设计。换地点就换声学，不靠画面字卡提醒。
2. **世界湿，Lyra 干。** 所有环境、人物、脚步都进各自地点的混响；Lyra 的声音和她的高跟鞋永远是干的。
3. **人声只做纹理。** 站厅广播、摊贩叫卖、人群交谈一律听不清内容（颗粒化或远距离），不出现任何品牌名、真实队名或助威口号。
4. **设备不发声。** Gateway、Portal、Paragon 没有风扇声、电流声、开机音。它们存在的声音证据只有 Lyra。

## 5. UI Sound（纸 / 木 / 玻璃）

### 5.1 规则

1. **只用三种真实材料**：纸（信息被写下）、木（一个温和的确认）、玻璃（Lyra 的存在）。每一个 UI 音都必须能由拟音师用真实物体录出来；代码版的合成参数只是它的替身。
2. **不用电子提示音**：没有正弦 beep、方波 blip、上行三音「成功」提示、振动马达声。`synth.py` 里的 `ui_tick`（正弦）与 `ui_confirm`（双正弦）在本片**不使用**（附录 B）。
3. **电平**：UI 声部单独测量，LUFS-M ≤ −18，样本峰值 ≤ −14 dBFS；与同时刻对白至少相差 10 LU。实际上本片的 UI 音都不和台词重叠。
4. **空间**：UI 音属于屏幕，和 Lyra 一样偏干（送 0.9 s 小房间混响 ≤ 20%），不进站厅的 3 s 混响。
5. **节奏**：UI 音落在十六分音符网格或画面事件上；「嗒」「点」这类瞬态优先对齐网格。跟随画面的微事件（逐字轻嗒、翻牌）按 05 §10 的精确时刻放到样本上，不取整到帧。

### 7.3 与画面同帧

- **叮 ① = X 两笔交叉的那一帧（57.5，第 1725 帧）**：铅笔笔画（左下 → 右上，来自 Seat 7 下面那道线）与钴蓝笔画（右下 → 左上，来自 Lyra 路线卡上的路线）在中心交叉、同时转白，1 帧闪白。第一声铃必须在这一帧的第一个样本上。

### 7.4 含义

- **叮 ①（E6，原始公交铃）= 提问。** 公交下车铃本来就是乘客的「请求」。它是旧的、属于人的、模拟的，是陈师傅 31 年的声音。
- **叮 ②（B6，玻璃 + 钢）= 城市回答。** 玻璃和不锈钢正是 LiveX 节点的材料（Gateway 的玻璃屏、Paragon 的拉丝不锈钢）。上行纯五度是八度之外最稳定的音程，听起来像「确认」，不像「警报」。
- **40 Hz = 回答有实体。** Physical AI：这个回答是有重量的，它就在现实空间里。
- **空五度 E–B 本身不分大小调**，所以 Logo 可以放在任何品牌语境里；影片里是后面的 G♯ 把它变成「被回答了」。

### 7.6 使用规则

1. 永远是 **E → B，上行**；两声间隔永远 **0.5 s**，不随其他配乐速度改变。
2. 不移调、不反向、不加混响尾巴以外的效果；不叠加人声或品牌口号。
3. 第一声必须来自同一段原始公交铃录音；第二声必须是玻璃 + 钢的合成体。
4. 40 Hz 与任何持续低音不同时出现：影片里 Sub E1（41.2 Hz）在 57.0 已经释放，避免 1.2 Hz 的拍频。
