速度与网格：120 BPM，4/4，一小节 = 2.0 秒；六个段落落在小节线：HUMAN 0–10（1–5 小节）/ AI 10–20（6–10）/ REVEAL 20–28（11–14）/ JOURNEY 28–42（15–21）/ CITY 42–52（22–26）/ AI CITY 52–60（27–30）。
和声弧线即故事：按选定概念《7 路》移调到 E——E 小调（Dorian 色彩：Em9 → Cmaj7 → G/B → D6）代表迷路与陌生；结尾 AI CITY 转入 E 大调（Emaj9 绽放）代表城市回答了她。调性来源 = 1980 年代公交下车铃基频 E6（1318.5 Hz，非谐泛音 1 / 2.76 / 5.40）。00–42 秒半速律动（体感 60），42 秒起全速。
Lyra 动机（Leitmotif）：三音玻璃质感 FM 钟声（载波:调制 = 1:3.5，调制指数衰减），首次出现为小调 G5–B5–E6（Lyra 第一次开口）；每当 Lyra 在新地点出现时重复同一动机。站点铃：每个编号站一声合成公交铃「叮」（E6）。Sonic Logo = 「叮—叮」：原始公交铃 E6 + 玻璃钢质合成铃 B6（上行纯五度）+ 40 Hz 低频，与 X 两笔交叉同帧；之后大调动机 G#5–B5–E6 轻声收尾。
配器（electronic + organic，非 EDM、非企业配乐）：毛毡钢琴（非谐和泛音 + 逐泛音衰减 + 软锤噪声，暗色低通）；FM 玻璃钟（Lyra）；温暖失谐锯齿 Pad（每声部 3 振荡器 ±7 音分、慢速滤波扫频、宽立体声）；正弦 Sub（轻度饱和）；有机打击（共振带通木鱼/木质点击、摇铃沙锤、手拍）；柔和底鼓（音高包络 115→44Hz）；噪声上升音、低频 Boom（62→28Hz）、反向钟声吸气、立体声呼啸（带通扫频 + 声像移动）。
编配与能量：A 段极简（钢琴稀疏单音、D1 低频长音、呼吸与房间底噪，约 -21 LUFS 的亲密感）；B 段 Lyra 动机 + Dm9 Pad + 心跳式 Sub 脉冲（每小节 1、3 拍）+ UI 提示音，18–20 秒上升音 + 反向钟声；C 段 20.0 秒 Boom + 宽 Pad（Bbmaj9 → F/A）+ 钢琴旋律，无鼓，漂浮；最后一小节木质点击铺垫；D 段半速有机律动（底鼓 1、2&、4&，拍手在 3，沙锤八分，木鱼切分，Sub 八分脉冲），每个新地点动机重现；E 段推进（底鼓更密、16 分踩镲、拍手 2/4、Bass 16 分、滤波逐小节打开），每个剪辑点一声短玻璃音，49.75 秒上升音，51.75 秒一拍静默；F 段 52.0 秒 Boom + D 大调绽放 + Sub D1 长音 + 钢琴，Logo 时刻大调动机 + 软底鼓，57.5 秒 UI 确认音收尾，长混响尾音。
混音：钢琴/玻璃/Pad 送 3.6 秒大厅混响，鼓/打击送 1.0 秒房间混响；Pad 与 Bass 对底鼓做轻度侧链；总线 25Hz 高通 → 胶水压缩（阈值 0.5、2.2:1）→ tanh 软削波 → 前瞻限幅（-0.9 dBFS）；成片响度目标 -14 LUFS / -1 dBTP（X/社交平台），保留从开场到高潮约 8–10 LU 的动态弧线。
